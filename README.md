# CareBridge

Neighbors helping neighbors, one request at a time.

CareBridge is a neighborhood mutual aid board. People post a small need or a kind offer, a neighbor nearby claims it, helps, and marks it done. It is free, needs no sign up, and works offline on the device.

Built for Code for Change, a global online student hackathon about practical technology for positive change.

## What it does

- Browse a board of needs and offers by category: Food, Health, Learning, Errands, Home
- Search, filter by type and status, and sort by newest, most urgent, or most loved
- Post a need or an offer with validation, so every post is clear enough to act on
- Claim a post as the helper, mark it done, or reopen it if plans change
- Love a post to show support
- See live neighborhood impact: open, claimed, done, and helper counts
- Everything is saved in localStorage, so the board works offline and survives a refresh

## Run it

```bash
npm install
npm run dev
```

## Test it

```bash
npm test
```

## Build it

```bash
npm run build
```

The build output in `dist/` is a static site. It can be hosted on GitHub Pages or any static host.
